# Blackwell is sm_120 and needs a CUDA 12.8+ toolchain, so install a matching
# PyTorch first, e.g.
#   pip install torch --index-url https://download.pytorch.org/whl/cu128
# then either a prebuilt wheel or a source build:
#   pip install flash-attn --no-build-isolation
# A source build needs `packaging`, `ninja` and ~30-60 min; set MAX_JOBS to
# bound memory (MAX_JOBS=4 pip install flash-attn --no-build-isolation).
#
# FlashAttention-2 is REQUIRED: the code does not fall back to sdpa or eager.
# Do NOT assume the install worked -- flash-attn wheels have historically
# targeted sm80-sm90, and one built for the wrong architecture imports cleanly
# and is then never used. Run
#   ./run_pipeline.sh preflight
# which runs the kernel and reports what actually executed. PyTorch's own
# pinned FLASH_ATTENTION backend is used when the package is absent; that is the
# same algorithm, not a downgrade to sdpa.
