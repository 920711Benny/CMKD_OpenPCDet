# Install from a local export package

If the GitHub remote does not yet contain the latest local work, use one of the local export packages generated by `scripts/package_release.sh`.

## Option A: tar.gz source package (simplest)
On the source machine:

```bash
cd CMKD_OpenPCDet
bash scripts/package_release.sh
```

Copy the generated `dist/*.tar.gz` file to the target machine, then run:

```bash
mkdir -p ~/packages
cp /path/to/CMKD_OpenPCDet-*.tar.gz ~/packages/
cd ~
tar -xzf ~/packages/CMKD_OpenPCDet-*.tar.gz
cd CMKD_OpenPCDet
```

After extraction, continue with the normal setup flow in `README.md`.

## Option B: git bundle (preserves git history)
On the source machine:

```bash
cd CMKD_OpenPCDet
bash scripts/package_release.sh
```

Copy the generated `dist/*.bundle` file to the target machine, then run:

```bash
git clone /path/to/CMKD_OpenPCDet-*.bundle CMKD_OpenPCDet
cd CMKD_OpenPCDet
git checkout work || git checkout main || git checkout master
```

After that, continue with the normal setup flow in `README.md`.
